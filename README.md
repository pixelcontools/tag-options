# tag-options

Animated guild-tag options for the PIXELCONS guild on [geopixels.net](https://geopixels.net).

- **Live page:** `docs/index.html` (served by GitHub Pages from `/docs`). Open *Classic tag styles* or *New tag styles*, pick a companion image from a picture grid (or none), click a tag to copy or download its HTML.
- **Tag files:** `docs/tags/plain/` (tag only) and `docs/tags/with-<companion>/` (tag + a companion image on the right, 84 px tall; generated by `tools/build.py`). Companion images live in `docs/tags/companions/`.
- **Rebuild the page:** `python tools/build.py` (reads `docs/tags/`, writes `docs/index.html`).

Tags use only inline SVG animation and the site's built-in `maplibregl-user-location-dot-pulse` keyframes: no `<script>`, no `<style>`.

- **Scene tags (22, 24-29)** are PNG banners; the gallery's *Animated hearts* dropdown (None / Few / All) adds a yellow heart on the left and a blue heart on the right (Few), plus small floating hearts (All). Their art is generated by `tools/art/scenes.py` and the tag HTML by `tools/art/make_tags.py`.

- **Add a companion image:** `python tools/art/make_companion.py IMAGE --id name --name "Label"` converts any image to a size-checked PNG fragment (256 colours, shrinks to fit a character budget), then `python tools/build.py`.
- In the popup, **User profile** view previews the tag inside a copy of geopixels.net's profile panel (AriaPokoteng's profile) with a screen-width slider, to show how the companion image wraps on narrow phones (`docs/profile-preview.html`).
